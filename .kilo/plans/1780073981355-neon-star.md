# Pivot to Fully Free — Remove All Monetization

> **Status:** Plan — ready for implementation  
> **Decision:** All features free, no tiers, no paywalls, no upgrades  
> **Distribution:** DMG + Netlify + Sparkle auto-updates (unchanged)

---

## Goal

Remove every trace of monetization from the app. All features that were previously Pro-gated (burn rate, cost transparency, multi-AI, unlimited profiles, custom thresholds, advanced icons, usage export, etc.) become universally available. The app is now a single-tier, fully-free product.
